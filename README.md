# Sakthi Dental Clinic – Web App

A clean, responsive single-page web portal designed for Sakthi Dental Clinic (Hosur), highlighting comprehensive dental care for women, children, and families.

---

## ✨ Features

- **Modern Glassmorphic Design**: Frosted-glass components (`backdrop-filter`), vibrant pastel light gradients, and smooth glowing accents.
- **Client-Side Routing**: Fast, lightweight hash-based navigation (`#home`, `#about`, `#treatments`, `#faqs`, `#contact`, `#privacy`) with no external framework overhead.
- **Dynamic Content Rendering**: JavaScript-driven treatment catalog and interactive accordion FAQs.
- **Interactive Testimonial Carousel**: Automated rotation with manual navigation controls.
- **Form Validation**: Native client-side validation for appointment requests and inquiries.
- **Zero Dependencies**: Pure HTML5, modern CSS, and vanilla JavaScript—super fast load times and minimal resource footprint.

---

## 🛠️ Tech Stack

- **Markup**: HTML5 Semantic Elements
- **Styling**: Modern CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism, CSS Animations)
- **Scripting**: Vanilla JavaScript (ES6+)
- **Typography**: Google Fonts (*Outfit* & *Plus Jakarta Sans*)

---

## 🚀 Live Demo & Deployment

Deploy effortlessly to GitHub Pages:
1. Push code to the `main` branch.
2. Navigate to **Settings** > **Pages**.
3. Under **Branch**, select `main` / `root` and click **Save**.
